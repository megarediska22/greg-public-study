# Адаптивное обучение, доступ и повторение

## AD-01 · Независимые состояния

Урок содержит отдельные признаки: **COMPLETED** — фактически выполнен по правилам урока, **PLACEMENT_CONFIRMED** — диагностика подтверждает всё ядро его явного профиля пропуска, **RECOMMENDED** — предложен с причиной, **AVAILABLE** или **LOCKED** — доступ. AVAILABLE и LOCKED взаимоисключающие. Остальные признаки сочетаются. Пройденный урок всегда AVAILABLE. Рекомендация сама по себе доступа не выдаёт. PLACEMENT_CONFIRMED может относиться к ещё закрытому уроку, если ученик пока не выбрал нужный маршрут. Подтверждённый пропуск хранится отдельно от COMPLETED, историю и процент пройденного он не увеличивает.

Профиль входной точки из PL-03 и профиль пропуска **конкретного урока** служат разным решениям. Рекомендованный вход может обойти часть маршрута без утверждения, что все пройденные мимо уроки освоены. Профиль пропуска задаётся автором по основному учебному результату и требуемым критериям. Групповое подтверждение принимается только для совпадающего среза. Доступные умения из blueprint помогают подобрать материалы. Все 385 педагогических рёбер остаются картой опор. ## AD-02 · Выдача доступа

1. При первом входе базовая A1-точка доступна. По выбору ученика можно открыть первое вводное занятие Pre-A1 и переключиться обратно без отметок о прохождении. Пользователь с сохранённой историей получает прежние пройденные уроки, точку продолжения и существующие валидные права доступа. Правила действующей миграции остаются основанием для чтения этой истории.
2. В целевом маршруте принятое рекомендованное место выдаёт доступ **одному готовому уроку**. Прямой вход возможен в точки PL-03 и в перечисленные адресные опоры из PL-03. Для bp-pre-02 требуется подтверждение чтения латиницы или завершение bp-pre-01. Для фокусного do-does нужна достаточная опора по be — CONFIRMED по K-A1-BE или фактически завершённый to-be. Иначе предложить to-be. Для прямого unit-030 нужна опора по ориентированию — CONFIRMED по K-A1-ORIENT или завершённый hours-and-signs; иначе предложить hours-and-signs при подходящем профиле либо A1-вход. Для адресного to-be можно открыть направляемый маршрут при CONFIRMED по K-P-LAT; иначе сначала предложить Pre-A1 или основной старт с опорами. Ветка Pre-A1 факультативна.
3. При обычном прохождении открыть один следующий урок по порядку выбранной цепочки после COMPLETED текущего. Исключение для контрольных переходов изложено в AD-03. Для ранее полученного права повторно проходить этот урок не требуется. Индивидуальный пропуск возможен по явному действию ученика у доступного урока, если все критерии его проверенного профиля CONFIRMED. Допустимо подтверждение из уроков по EV-03; признак PLACEMENT_CONFIRMED ставится только при полностью диагностической паре для каждого критерия профиля. Сам пропуск выдаёт доступ следующему, но текущий остаётся доступным и непройденным.
4. Прямые старты, пропуск и контрольный переход опираются на небольшое утверждённое описание точек, а не на вывод из соседства, любой метки CEFR или полного графа. Профиль без объявленного набора критериев не даёт индивидуального пропуска. Для пилота bp-pre-01 допускает пропуск по точному K-P-LAT. Пример будущего профильного кандидата — hours-and-signs при наличии отдельного независимого свидетельства по чтению часов, формам указания времени и вопросу о них. Срез K-A1-ORIENT один такого профиля не закрывает. Остальные уроки до утверждения профиля проходят обычным путём.
5. Выданные права монотонны для данного каталога, в том числе при REVIEW, повторном тесте и несовместимой версии методики. Выбор более ранней практики или отказ от рекомендации не закрывает прежний маршрут. Новый сигнал может изменить совет и остановить **ещё не принятый** профильный пропуск. Локальный прогресс не переносится на другое устройство автоматически. Явный подтверждённый сброс пользователем имеет собственный смысл.
6. Готовность релиза проверяется до показа активной кнопки. При выборе повторно сверить актуальность профиля и доступность урока. Для недоступного планового bp-a1-01 использовать действующий начальный to-be. Если отсутствует другая точка, выбрать ближайшую более раннюю из полностью доступных и удовлетворяющих профилю. Если такой нет, предложить проверенное место продолжения или начальный урок. Отсутствующую вводную подготовку обозначить текстом и сохранить выбор A1. Пока установлен только действующий линейный курс без утверждённого адаптивного режима, сохранённый доступ остаётся исходным, а новые маршруты доступны только в согласованном пилоте. Будущие ID не добавляются в историю текущего каталога.

## AD-03 · Контрольные точки и переходы

В [таблице](CHECKPOINT_SPEC.csv) перечислены 13 контрольных точек. Для обычной контрольной действует условие фактического завершения учебной практики. Её независимый результат обновляет конкретные знания и даёт советы. Первая попытка без помощи и повтор на новом материале следуют EV-01–03. У bp-pre-04 результат предлагает старт и нужную опору, а основной A1 доступен по выбору.

Два перехода с проверкой готовности — bp-a1-08 → unit-042 и unit-061 → unit-062. Если контрольная показала назначенные самостоятельные действия, переход предлагается как самостоятельный. После практики с помощью или при нехватке свидетельств предложить короткую обратную связь и **«Продолжить с опорой»**. Эта команда выдаёт один следующий урок после завершённой попытки контрольной (все её назначенные целевые задачи предъявлены и отмечены как ответ, пропуск или не знаю), даже если ещё нет CONFIRMED или COMPLETED. Она не обходит отдельные допуски для прямого диагностического старта. Повторение до перехода добровольно. В bp-a2-07 результат сводится к текстовым умениям и рекомендациям по повторению. Следующий уровень не выдаётся.

## AD-04 · Рекомендации во время обучения

| Свидетельство | Действие |
| --- | --- |
| Один диагностируемый минус | Дать локальное объяснение, сохранить статус подтверждённого умения. Если подтверждения ещё нет, применить EV-03. |
| Повторные самостоятельные ошибки в новых семействах с одной ясной причиной | Пересчитать GAP или REVIEW. Если тренируемая цель текущая, предложить её повтор. Если проблема в явной предшествующей опоре, предложить соответствующий урок. |
| Противоречивые результаты, неоднозначный ввод или несколько возможных причин | Предложить короткую самостоятельную проверку на новом узком материале. Отсутствие ответа оставить отдельно. |
| Успех после подсказки или исправления | Подтвердить практику и продолжение по правилам урока. Предложить свежую проверку, когда нужно независимое свидетельство. |
| Свежая пара самостоятельных успешных задач после проблемы | Восстановить CONFIRMED по EV-03, снять активный совет по этой причине. |
| Долгое отсутствие практики | При желании предложить обзор. Состояние знаний остаётся прежним. |

Совет привязан к критерию, назначенному элементу повторения и эпизоду проблемы. За один показ выводить одну главную рекомендацию: ближайшая предшествующая опора с GAP/REVIEW и ясной причиной, затем текущая цель с GAP/REVIEW, затем уточняющая проверка. Среди опор выбирать по наименьшему числу связей в карте предпосылок, затем по позиции урока в курсе и по ID. Учитывать только связи, относящиеся к текущему критерию. Повторно использовать совет того же эпизода только по запросу. Отклонение убирает совет для данного эпизода и сохраняет кнопку продолжения. Возврат навыка до CONFIRMED закрывает эпизод, а свежая пара ошибок позже может открыть новый. Для GAP без прежнего подтверждения единичный успешный ответ и MIXED не создают повторный эпизод. Повтор не становится бесконечным требованием доступа. Адресная практика оставляет возможность вернуться к сохранённому прежнему месту.
