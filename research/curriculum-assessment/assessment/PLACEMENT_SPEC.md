# Входная диагностика и учебный старт

Цель — предложить полезную точку начала текстового курса и назвать проверенные действия. Версия **pilot-v1** опирается на срезы [карты знаний](KNOWLEDGE_MODEL.csv). Обычный путь **20–28 заданий, ориентир 8–12 активных минут**. Выход после проверки латиницы занимает 4–6 заданий. Объём, длительность и пороги — гипотезы. Скорость сама по себе результат не меняет. [Исследование](../ASSESSMENT_RESEARCH.md)

## PL-01 · Вход, пауза и повтор

- **Начать с нуля.** Предложить «Подготовка к A1» с bp-pre-01 и «Сразу к A1» с bp-a1-01. Пользователь, которому трудно читать латиницу, может выбрать подготовку без теста.
- **Подобрать учебный старт.** По явному выбору показать охват, время и возможность остановиться. Начать с общего блока независимо от самооценки. Отказ ведёт к выбору маршрута. Действие доступно позже. Для вернувшегося пользователя основным остаётся «Продолжить обучение».
- **Прервать.** Сохранить порядок блоков, предъявленные задания, отправленные ответы, выбранную форму и указатель. При возвращении предложить продолжить тот же сеанс. Черновик не считается отправленным. «Завершить сейчас» закрывает незавершённый сеанс, показывает безопасный старт или прежний доступ с пометкой «Данных пока мало». Свидетельства черновика при этом не применяются к состоянию знаний и уровню доступа.
- **Повторить.** Выбрать свежие семейства для новой сессии. Свежим считается семейство, которое ещё не предъявлялось в этой или предыдущих диагностических сессиях и по которому нет ранее раскрытого ключа или учтённого свидетельства для данного критерия. Сохранить прошлые решения и выданный доступ. При несовместимой версии банка старый черновик архивируется. Новая диагностика добровольна. Для завершённого повтора состояние меняется по правилам EV-03.

## PL-02 · Блоки, ветвление и остановка

Пара на срез состоит из R и P на двух разных материалах и в разных семействах. Для P требуется самостоятельный ввод без видимого списка ответов или раскрывающих ответ элементов. Каждый слот имеет один критерий. Поддерживающие слова могут быть проще при сохранении проверяемой операции. Счётчик объёма учитывает каждое предъявленное задание один раз, в том числе пропуски. До итогового экрана ключи скрыты.

| Блок | Объём | Группы и решение |
| --- | ---: | --- |
| D0 | 4 | По паре для K-P-LAT и K-P-NUM. GAP по латинице ведёт к короткому завершению и bp-pre-01. CONFIRMED по латинице ведёт к D1. Иначе D0R. |
| D0R | 0 или 2 | Свежая пара для неясной латиницы. При CONFIRMED идти к D1. Иначе короткий неполный результат и предложение подготовки с правом выбрать A1. |
| D1 | 8 | По паре для K-A1-BE, K-A1-ASK, K-A1-ORIENT, K-A1-NOTE. Единое ядро умеренной сложности. При **трёх из четырёх CONFIRMED** перейти к D2-UP, иначе к D2-BASE. Числа влияют на старт и не препятствуют проверке других сильных сторон. |
| D2-BASE | 8 | По свежей паре тех же четырёх срезов. Контексты короче, слова знакомее. Критерий и требуемая операция сохраняются. |
| D2-UP | 8 | По паре для K-A1-NOW, K-A1-PAST, K-A2-CONSTRAINT, K-A2-WRITE. Проверяются выбор по смыслу, совместное применение условий и короткий ответ. |
| D3 | 0–6 | Уточнение по правилам ниже или добровольная верхняя текстовая проверка. |

**Выбор D3.** Применять профиль PL-03 по свежим данным. Когда раннего адресного GAP нет, брать ближайший следующий профиль выше последнего полностью подтверждённого и уточнять его первый неподтверждённый срез. Если нужная пара недоступна, этот срез уже уточнялся в D3 или срез имеет GAP, профиль остаётся недостижимым в этой форме. Закончить на последнем достаточном профиле. Порядок внутри профиля — K-P-NUM, K-A1-BE, K-A1-ASK, K-A1-ORIENT, K-A1-NOTE, после D2-UP также K-A2-CONSTRAINT и K-A2-WRITE. REVIEW можно уточнить новой парой. Для GAP адресная рекомендация уже оправдана. По каждому срезу не более одной пары D3. После D2-BASE уточнять только до профиля unit-042. Когда профиль unit-062 подтверждён и значимых ранних GAP/REVIEW нет, оставшиеся пары можно предложить для K-A2-GIST, затем при CONFIRMED по нему для K-A2-MEDIATE. Дополнительная пара предъявляется целиком при наличии двух свежих семейств и свободного бюджета. Максимум три пары D3. Упрощённые задания в D2-BASE помогают различить сложность формулировки и владение действием. Для нового старта их свидетельства сопоставимы с ядром только при сохранении критериев и требуемой операции.

**Остановка.** После D0 или D0R действует короткий выход. После D2 закончить, если пара не изменит адресный совет, ученик пропускает верхнюю проверку, свежих семейств нет или достигнут предел D3 либо 28 предъявлений. Граничное MIXED, отсутствие обязательного блока и дефицит вариантов отображаются как недостаток данных. Автоматически законченный сеанс, включая частичный охват, применяет пригодные знаки. Ручное закрытие до завершения действует по PL-01. При нехватке пары в обязательном блоке завершать с частичным результатом до перехода дальше.

**Источники знаков.** Ветвление и совет по ходу используют свежие ответы данного сеанса. При завершении отдельно вычислять состояния текущей сессии и обновить историю по EV-03. Для адресной практики допустимы актуальные GAP/REVIEW из обоих результатов. Для нового позднего старта действуют требования свежести PL-03. Предыдущий результат не заменяет новую пару для выбора D2. Угадывание ограничивается требованием P и разных семейств. Контрольные поля одного случая не превращаются в несколько независимых ответов. [Правила свидетельств](EVIDENCE_RULES.md)

## PL-03 · Рекомендуемый старт

Сначала искать значимый **GAP или REVIEW** в порядке **K-P-LAT → K-P-NUM → K-A1-BE → K-A1-ASK → K-A1-ORIENT → K-A1-NOTE**. Адреса — bp-pre-01, bp-pre-02, to-be, do-does, hours-and-signs, unit-030. Предложить первый применимый для ближайшего учебного старта пробел. Неизмеренный срез остаётся неопределённостью. Подтверждённые сильные стороны A2 сохраняются при ошибке A1. Для фокусного урока с отсутствующей предшествующей опорой предложить доступный подготовительный путь по правилам AD-02. Pre-A1 можно пропустить.

Если значимого пробела нет, выбрать самую позднюю из точек, для которой **все** перечисленные срезы CONFIRMED как в свежей автоматически завершённой сессии, так и в обновлённой истории. Отдельный поздний минус может не изменить историческое CONFIRMED, но на экране текущего результата отображается как недостаток свежего подтверждения, если пара на данном срезе противоречива. Профиль отражает достаточность выборки для маршрута и охватывает опубликованные действия, необходимые для входа. Предыдущие уроки сохраняют свой статус.

| Точка | Нужные срезы |
| --- | --- |
| bp-a1-01 | Резервный старт. При неясной латинице рядом предложить bp-pre-01. |
| hours-and-signs | K-P-LAT, K-A1-BE, K-A1-ASK. |
| unit-042 | Предыдущий профиль + K-P-NUM, K-A1-ORIENT, K-A1-NOTE. |
| unit-062 | Профиль unit-042 + K-A2-CONSTRAINT, K-A2-WRITE. |
| bp-a2-07 | Профиль unit-062 + K-A2-GIST, K-A2-MEDIATE. Предложить итоговую текстовую проверку. |

Предпосылки из карты направляют адресный совет. Обязательный допуск указан в профиле и AD-02. Рекомендуемые опоры объясняют вариант практики и оставляют путь вперёд. K-A1-NOW и K-A1-PAST дают адресные советы для соответствующих тем. Эти результаты не являются условием входа в раздел о покупках. MIXED, PRELIMINARY и UNKNOWN не подтверждают следующий профиль. На экране результата предложить более раннюю доступную точку.

**Сохранённая история.** По умолчанию возобновить текущий доступный маршрут. Если новый результат выявил устойчивый пробел, показать адресный совет рядом с сохранённым стартом. Без новых оснований выбрать прежнее место вместо отката. Более поздний старт с достаточным свежим профилем предлагается отдельно. После адресного повторения можно предложить новую диагностику на свежих семействах или продвижение по текущему маршруту. Уже открытый поздний урок доступен сразу. Разрешение доступности для плановых ID и выдача ровно выбранной точки определены в AD-02. Верхний результат означает только «эти текстовые задания оказались вам по силам».
