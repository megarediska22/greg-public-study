# Порядок будущей реализации · Lessons & QA

Реализация начинается по отдельному поручению. Сначала согласовать текстовые цели, затем создавать оригинальные задания пакетами. Пакеты описывают порядок подготовки материалов и проверки, а расположение урока для ученика задаёт [единая последовательность](LESSON_SEQUENCE.csv). Якорь вставки — стабильный ID. Числовая позиция меняется по мере расширения.

## Требования к каждому авторскому материалу

1. Задать цель через действие и указать источник, адресата, ограничения и ожидаемый результат. Разметить основной `objective_id`, сопутствующие цели и проверяемые предпосылки. Уровень обосновать длиной текста, знакомостью, количеством ограничений, допустимой опорой и длиной ответа.
2. Сначала дать оригинальный пример, затем упражнение на знакомом материале. Независимое задание использует другой текст или ситуацию. Подсказки, демонстрационные ответы и предыдущие задания не раскрывают целевой ответ. Для задания на чтение обязательна смысловая операция, например выбор времени с учётом границы, а не перенос видимой цифры без решения.
3. При самостоятельной проверке указать, что ученик пробует ответить до открытия подсказки. В разборе отдельно назвать проверяемую цель, помощь и повтор. Когда нужна повторная попытка для подтверждения, дать сопоставимый по сложности текст с другими фактами. Результаты к одному тексту не считать независимыми свидетельствами.
4. Для детерминированной проверки задать требование, которому соответствует обозримый набор естественных вариантов. Целый ответ должен содержать существенные части в одном сообщении. Варианты регистра, сокращений, времени, пунктуации и порядка допускаются там, где они не меняют смысл и не противоречат условию. Если разумных ответов слишком много, сузить контекст или дать отдельную практику с эталоном и памяткой для самопроверки свободы формулировки. Такой формат имеет статус практики.
5. Перед сдачей редактор сверяет инструкцию, дистракторы, принятые варианты и обратную связь. Второй прогон проверяет соответствие задаче и уровню, логику фактов, естественность AmE и стабильность смысла в русском объяснении. Использовать вымышленные контактные данные и собственные материалы.

Выборочный независимый перенос отдельных слов даёт сведения о проверенной части списка. Для вывода по всему набору нужны свидетельства по соответствующим единицам. Поэтому для конкретных словарных целей с фиксированным объёмом целевая карта сохраняет `PRACTICED`, при этом в уроках запланирован независимый перенос выбранных слов.

## Совместимость с текущим курсом

Сохранять существующие ID уроков, шагов и вопросов и преемственность уже подтверждённых результатов. Для новых материалов выделять новые ID при будущей реализации. Существующая история выполнения должна по-прежнему открывать ранее доступные результаты. Новая практика подтверждается её выполнением. Если интеграция меняет путь уже начавших пользователей, нужен отдельный согласованный сценарий проверки старого частичного и полного прогресса. Для новых вставок проверяются чистый старт, возврат к уроку, старый прогресс, точность ответов и доступ к повторению. Карта последовательности остаётся образовательным артефактом.
