# Этап 03 · Curriculum Blueprint

Целевая текстовая программа американского английского для русскоязычной аудитории. Проект опирается на [исследование стандартов](../METHODOLOGY_BASELINE.md) и [аудит 121 урока](../audit/AUDIT_REPORT.md). После реализации в программе предлагается 140 занятий, из них четыре вводных по выбору. Документы составляют задание для направления 04 и исходные данные для будущей методологии диагностики.

| [LESSON_SEQUENCE.csv](LESSON_SEQUENCE.csv) | 140 строк. Стабильные ID, рекомендуемая последовательность, цели и знания, необходимые для занятия. |

## Как читать идентификаторы и статусы

- CSV записаны в UTF-8 с разделителем-запятой. Списки в ячейках разделены вертикальной чертой. `original_position` ссылается на снимок аудита. Каждая новая строка имеет плановый `lesson_id` с префиксом `bp-`, который не добавлен в исходный код. `BP-…` — новые уточнённые `objective_id`, прежние ID целей унаследованы из аудита.
- `OPTIONAL_PRE_A1` и `CORE_A1_A2` — два педагогических маршрута. `position` показывает положение в общей карте, `route_position` — порядок внутри маршрута. Начало ядра — `bp-a1-01`. `track` описывает тему или линию повторения для будущей рекомендации. Она сама по себе не определяет доступ.
- `REQUIRED` описывает знание, нужное для действия. Изучение в конкретном уроке — один из способов его приобрести. `RECOMMENDED` и `SPIRAL` указывают полезную опору и возврат к знакомому с другой задачей. `PREVIEW` отмечает допустимое раннее знакомство. `INDEPENDENT` означает, что локальной опоры достаточно. Для технического доступа потребуется отдельное решение.
- `current_status` сохраняет вывод аудита. `target_status` и `planned_lesson_statuses` описывают ожидаемое состояние после реализации. `ASSESSED` означает возможность проверить отдельное действие на подходящем новом материале. `PRACTICED` означает упражнение с возможной опорой, `INTRODUCED` — объяснение. `INSUFFICIENT_EVIDENCE` показывает недостаток исходных свидетельств. `DEFERRED_FORMAT` отмечает цель вне выбранного формата. Условия независимости и пределы текущих свидетельств сохраняются в отдельных полях.
- `REORDER` переносит время введения двух функций из существующих уроков, сохраняя их ID и относительный порядок. `CORRECT_REVIEW` уточняет две ссылки в уроках, сохранённых по результатам аудита. `source_path` и `source` указывают путь к источнику относительно корня репозитория для существующих уроков, а для плановых — спецификацию в этой папке.

Направление 00 использует итоговые объёмы и пакеты. Направление 04 берёт соответствующие строки матрицы и спецификаций, готовит оригинальные материалы и проверяет их по критериям. После отдельного поручения направление 03 сможет использовать карту знаний и свидетельств при обсуждении будущих рекомендаций. [Результаты аудита](../audit/README.md)
