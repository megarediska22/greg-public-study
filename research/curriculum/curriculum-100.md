# Curriculum for 100 new lessons

This proposed continuation appends #22–#121 after the existing 21 A1 lessons. #22–#26 are the pilot. Level labels are instructional targets for functional reading and controlled written performance. A1→A2 is a planning band for gradual transition.

**How to read the tables.** Each row inherits the explicit CEFR band in its ten-unit block heading: A1 for #22–#41, A1→A2 for #42–#61, and A2 for #62–#121. Prerequisites are the earlier language or task knowledge to teach from. Linked review numbers identify concrete retrieval opportunities rather than additional unlock conditions. The sequential course order still applies. **C** is single choice, **B** is a cued text blank, and **W** is constrained written production. A mock message or dialogue is read on screen. Each checkpoint combines an unfamiliar set of facts with taught language and introduces zero required new vocabulary. The exit targets describe success on designated items using new facts and are authoring criteria. The first five remain scaffolded A1 tasks; the level of a genre alone does not establish independent proficiency.
